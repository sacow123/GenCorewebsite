GENCORE TEMPLATE GUIDE

스크류 채널 형상별 CAT1 · CAT2 선택 가이드

스크류 채널 형상에 맞는 Object Feature를 선택하여 의도한 채널 형상을 안정적으로 가공하기 위한 기준입니다.

Flat 채널CAT1을 선택합니다.
Tapered 채널CAT2를 선택합니다.
검토 순서가공 결과 → STL 비교 → 확대

1스크류 채널 형상

스크류 채널은 단면 형상에 따라 두 가지로 구분됩니다. 형상에 맞지 않는 Object Feature를 선택하면 의도한 면 형상이 재현되지 않을 수 있습니다.

형상 판별
채널 하단이 직각으로 마감되면 Flat, 경사면으로 이어지면 Tapered로 구분합니다.

2Gencore 템플릿 선택지

Gencore 템플릿에서 스크류 채널 가공 시 Object Feature는 두 가지 중 하나를 선택합니다.

Object Feature카테고리사용 툴권장 채널 형상
Object Feature 1CAT1T16_M1.5FL_L15Flat (직각)
Object Feature 2CAT2T15_M1.5FR_L15Tapered (각진)

3직각 형태 (Flat) 스크류 채널

직각 형태 채널에서 CAT1과 CAT2의 가공 예상 결과를 순서대로 비교합니다.

CAT1 · T16_M1.5FL_L15

CAT2 · T15_M1.5FR_L15

결론: Flat 채널은 CAT1을 선택합니다.

직각 형태의 스크류 채널은 Object Feature 1 (CAT1)과 Flat 툴로 가공하는 것이 적합합니다.

4각진 형태 (Tapered) 스크류 채널

각진 형태 채널에서 CAT1과 CAT2의 가공 예상 결과를 순서대로 비교합니다.

CAT1 · T16_M1.5FL_L15

CAT1 사용 시 주의
CAT1을 선택하여 Flat 툴로 가공하면 경사면이 계단 형태로 나타납니다.

CAT2 · T15_M1.5FR_L15

결론: Tapered 채널은 CAT2를 선택합니다.

각진 형태의 경사면을 유지하려면 Object Feature 2 (CAT2)를 선택해야 합니다.

5최종 선택 기준

스크류 채널 형상선택할 Object Feature선택 이유
Flat (직각)Object Feature 1 (CAT1)직각 채널 형상에 적합
Tapered (각진)Object Feature 2 (CAT2)경사면을 계단 형태 없이 가공
가공 전 확인
STL의 채널 하단 형상을 먼저 확인한 뒤, Flat이면 CAT1, Tapered이면 CAT2를 선택하십시오.
