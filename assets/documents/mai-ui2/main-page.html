5.1.b.1. 공구 수명 설정 창

  • 각 공구의 수명을 키보드로 입력할 수 있습니다.
  • “Enable tool life notification” - 해당 공구가 설정한 수명에 도달하면 이미지 우측의 빨간 LED가 깜박거리도록 설정합니다.
  • “Do you want to reset all red LEDs?” - 현재 깜박거리고 있는 모든 빨간 LED를 끕니다.

5.1.c. 아이콘/ 알람

  • 모든 축을 원점으로 이동.

기계 전원이 켜진 직후 또는 의도치 않게 정지한 경우에는 반드시 실행해야 합니다.

  • 현재 각 축의 위치 좌표
  • G##: 좌표 종류
  • G-코드 라인 수
  • Feedrate: *.nc파일 상의 이동 속도
  • Unit/min.: 가공 중 실제 이동 속도
  • Unit/Rev.: 가공 과정 중 실제 회전 속도
  • RPM: 스핀들의 분당 회전 수
  • Tool #: 현재 스핀들에 장착되어 있는 공구 번호
  • 가공 경과 시간
  • E- stop: 긴급 정지 버튼

  • 에러 메시지, 가공 진행 상황 관련 메시지 등 여러 종류의 메시지가 뜹니다.

  • 기계에 문제 발생 시 경고 아이콘이 점멸합니다.

  • 서보 모터에 문제 발생 시 아이콘이 점멸합니다.
  • 스핀들에 문제 발생 시 아이콘이 점멸합니다.
  • 공기압이 0.5 Mph 보다 낮을 때 나타납니다. (에어 컴프레서를 확인하세요)
