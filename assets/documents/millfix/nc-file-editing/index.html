T11 공정부터 시작하도록 수정하는 방법

1편집할 NC 파일을 선택한 후 복사합니다.

2원본이 아닌 복사본을 메모장으로 열어 편집합니다.

3시작하려는 공정의 공구 번호를 확인합니다. 예시에서는 T11부터 시작합니다.

4Ctrl + F를 눌러 찾기 창을 열고, 시작할 공구 번호인 T11을 입력합니다.

5Enter 키는 한 번만 눌러 첫 번째 T11 공정을 찾습니다.

6첫 T11 공정을 찾았다면 그 위의 코드 전체를 삭제할 준비를 합니다.

7삭제할 부분 바로 윗 줄의 끝을 클릭합니다. 예시 화면에서는 'G0 G53 Z-3' 코드의 끝인 '3'입니다.

8스크롤바를 맨 위로 이동합니다.

9Shift 키를 누른 상태로 맨 앞의 코드 줄을 클릭하여 앞부분 전체를 선택합니다.

10Delete 키를 눌러 선택한 코드만 삭제합니다.

11수정이 끝났으면 파일을 저장합니다.

12저장한 파일을 다시 열어 첫 공정이 M06 T11 코드부터 시작하는지 최종 확인합니다.

최종확인NC파일의 이름을 잘 확인 후 가공 시작하시기 바랍니다.
