💰 공구 포켓 위치

🔔 공구 장착 전 확인

공구의 샹크 측면 또는 공구 케이스에서 공구 번호를 정확히 확인한 후, 해당 포켓에 올바르게 장착합니다.

📌 적용 공구 리스트

For Zirconia
T31_Z2.0B / T32_Z1.0B / T33_Z0.6B / T34_Z0.3B
For Hybrid ceramic
T35_G2.0B / T36_G1.0B / T37_G0.6B
For PMMA
T38_M2.0B / T39_M1.0B
Special purpose
T42_M1.5FL / T43_M1.0F / T44_M1.5R / T45_M1.6T

🔘 공구 세팅

⚙️ 초기 위치 확인

  • 대기 상태 (홈잉(Homing) 완료 직후) 에서는 A축이 약 +35° 기울어진 상태로 위치합니다.

🔍 공구 번호 확인

  • 각 공구의 번호를 확인한 후, 해당 포켓에 장착하십시오.

📥 공구 장착

  • 공구를 포켓에 끝까지 수직으로 밀어 넣으십시오.
🔔 공구가 비스듬히 장착되지 않도록 주의 하십시오.

📤 공구 탈착

  • 공구를 단단히 잡고, 장착 방향의 수직 방향으로 곧게 당겨 분리하십시오.
🔔 공구가 미끄러질 경우, 마른 천 또는 휴지를 사용하여 안전하게 분리하십시오.
