코드 번호 오류 메시지 및 상세 설명 (Messages & Descriptions) 비고 (Note)
A101 Insufficient air pressure for processing. (가공 시작을 위한 공압 부족)
가공 시작에 필요한 공압이 부족하여 가공을 시작할 수 없습니다.
• 에어 컴프레서 및 장비에 공급되는 에어 라인을 점검하십시오.
A102 Insufficient air pressure to open the chuck (척 개방을 위한 공압 부족)
• 수동으로 척 열기 버튼을 클릭했으나 공압 부족으로 척이 열리지 않았습니다.
• 에어 컴프레서 및 장비에 공급되는 에어 라인을 점검하십시오.
A103 Insufficient air pressure for spindle testing. (스핀들 테스트 가동용 공압 부족)
• 스핀들 테스트 회전 버튼을 터치했을 때 에어 공급이 부족한 상태입니다.
• 에어 컴프레서 및 장비에 공급되는 에어 라인을 점검하십시오.
A104 Processing stopped due to air pressure drop. (가공 중 공압 저하로 인한 정지)
• 가공 중 공압 공급에 문제가 발생하여 가공이 중단되었습니다. 공구 교체(ATC) 동작 중 압축 공기가 소진되면 장비가 정지합니다.
• 에어 컴프레서 및 장비에 공급되는 에어 라인을 점검하십시오.
A105 Collet chuck is open. Close chuck and try again. (콜릿 척 개방됨)
• 스핀들 테스트 가동 시 콜릿 척이 닫혀 있어야 작동합니다.
• 열기/닫기(Open/Close) 버튼을 눌러 콜릿 척을 닫고 다시 시도하십시오.
A106 Collet chuck cannot be opened while spindle is rotating. (회전 중 척 개방 불가)
• 스핀들이 회전하는 동안에는 콜릿 척을 열 수 없습니다. 스핀들 회전 여부를 확인하십시오.
• 회전 중이라면 스핀들이 완전히 정지한 후 콜릿 척 개방 기능을 사용하십시오.
A107 Open collet chuck and set tool number to 0. (콜릿 척 개방 및 공구 번호 초기화)
• 상황에 따라 장비가 자동으로 공구 번호를 0으로 설정합니다.
A108 Insufficient air pressure (공압 부족 경고)
• 확인(OK): 가공 계속 / 취소(NO): 가공 정지
• 참고: 공압이 부족하면 가공을 계속할 수 없습니다.
• 공압 부족 감지 후 복구를 위해 2분간 대기했으나 정상 범위 내 공압이 공급되지 않았습니다.
• 컴프레서 및 에어 라인 점검 후 계속하려면 확인을, 공구 교체를 중단하려면 취소를 터치하십시오.
A201 Tool change stopped due to insufficient air pressure (공압 부족으로 공구 교체 정지)
• ATC 동작에 필요한 공압이 부족하여 공구 교체 동작이 중단되었습니다.
• 정상 공압 복구를 위해 2분간 대기했으나 정상화되지 않아 동작을 멈췄습니다.
• 컴프레서 및 에어 라인 확인 후 다시 시도하십시오.
A202 Wait 2 minutes for required air pressure. (공압 복구 대기 중)
• 공압이 정상 범위에 도달할 때까지 최대 2분간 대기합니다. (대기 시간 표시)
A203 Tool number not available. (사용할 수 없는 공구 번호 입력)
• 입력된 공구 번호가 장비의 지원 범위를 벗어났습니다.
• 사용 가능한 공구 번호를 확인한 후 다시 입력하십시오.
• 지원 공구 번호 범위: T1 ~ T28
A204 Tool number is 0, but tool is mounted on spindle. (스핀들 장착 공구 제거 필요)
• 제어 프로그램은 공구가 없다고(T0) 인식하지만 실제 스핀들에는 공구가 끼워져 있습니다.
• 스핀들에 장착된 공구를 직접 확인하고 수동으로 제거하십시오.
A205 Tool number is set, but no tool mounted on spindle. (스핀들 공구 미감지)
• 제어 프로그램에는 공구 번호가 입력되어 있으나 실제 스핀들에는 공구가 없습니다. 장비 공구 번호가 자동으로 0 초기화됩니다.
• 공구가 부러졌거나 생크(Shank)가 콜릿 내부에 제대로 삽입되었는지 점검하십시오.
A206 Problem detected with the tool in use. (사용 중인 공구 이상 감지)
• 확인(OK): 무시하고 공구 교체 후 가공 계속 / 취소(NO): 가공 정지 및 수동 공구 제거
• 공구 파손 또는 마모 가능성이 있으므로 상태 점검이 필요합니다.
• 확인 터치 시 공구 교체 후 밀링을 계속합니다.
• 취소 터치 시 가공을 멈추고 공구를 수동으로 제거해야 합니다. (수동 제거 시 설정 페이지에서 공구 번호를 0으로 리셋)
• 가공 전후 측정된 공구 길이 차이가 기준값(0.15mm) 이상일 때 이상으로 판별됩니다. (UI 설정에서 판별 기준값 변경 가능)
A207 Ignore warning and proceed with tool exchange. (경고 무시 및 강제 가공 계속)
• 공구 이상이 감지되었으나 사용자가 확인(OK)을 눌러 가공을 계속 진행하는 상태입니다.
• 장비가 공구 이상을 감지했으므로 가공 품질과 장비 상태를 주의 깊게 확인하십시오.
A208 Stop machining. Manually remove tool. (가공 정지 및 수동 제거 안내)
• 공구 이상 감지 후 사용자가 취소(NO)를 눌러 공구 교체 동작을 멈췄습니다.
• 스핀들에 장착된 공구를 손으로 직접 빼내십시오.
A209 Failed to return tool to pocket (툴 포켓 공구 반납 실패)
• ATC 동작 중 공구를 포켓에 정상적으로 안착시키지 못할 때 발생합니다.
• 포켓 반납을 3회 시도했으나 실패했습니다.
• 잦은 발생 시 툴 포켓 청소, 포켓 좌표 캘리브레이션, 콜릿 척 내부 청소가 필요합니다.
A210 Attempt to return tool to pocket again. (포켓 반납 재시도 중)
• 공구 반납 실패 후 포켓 삽입 동작을 다시 시도합니다. (시도 횟수 표시)
• 최대 3회 반복하며, 3회 시도 후에도 실패하면 동작이 자동 정지됩니다.
A211 Failed to grab tool from pocket. (지정 포켓 공구 그립 실패)
• 지정된 번호의 포켓에서 공구를 파지하는 데 실패했습니다.
• 해당 번호의 툴 포켓에 실제 공구가 올바르게 들어있는지 확인하십시오.
A212 Tool touch sensor abnormality detected. (공구 터치 센서 이상 감지)
• ATC 시작 전 터치 센서 비정상 신호 감지 (터치 전에는 신호가 없어야 정상).
• ATC 동작 중 공구가 센서에 닿기 전 비정상 신호 감지.
• 터치 센서가 눌려 있거나 내부 접점에 문제가 있습니다.
• 센서 주변의 이물질과 분진을 깨끗이 청소하십시오.
• 손으로 센서를 눌렀을 때 부드럽게 정상 복귀하는지 확인하십시오.
• 복귀가 느리거나 신호가 불규칙하면 센서를 교체해야 합니다.
A213 Abnormality detected in tool held by spindle. (스핀들 장착 공구 이상 감지)
• 공구 상태 육안 점검 후 메시지에 따라 '예' 또는 '아니오'를 선택하십시오.
• 예(Yes): 공구 교체를 계속 진행합니다.
• 아니오(No): 교체를 중단하며 수동으로 공구를 제거해 상태를 확인해야 합니다. ('아니오' 선택 시 공구 번호 자동 0 초기화)
• 규격에 맞지 않는 공구를 장착하려 할 때 발생합니다 (생크 길이가 너무 길거나 짧은 경우). 제조사 권장 규격의 공구를 사용하십시오.
• 직경 1mm 이하의 미세 공구는 파손 여부를 육안으로 확인하기 어려우므로 자세히 검사하십시오.
A214 ATC is not open. (ATC 개방 안 됨)
• 확인(OK): 계속 / 취소(NO): 가공 정지 (공압 부족 시 계속 진행 불가)
• 실제 ATC 도어가 열려 있지 않은지 센서 표시를 확인하십시오.
• 공압을 차단하고 손으로 포켓 슬라이드를 움직여 보십시오. 부드러워야 합니다.
• 기구부 상태가 정상임에도 경고 반복 시 센서 점검 (센서 간격 및 내부 점등 LED 확인).
A215 ATC is not closed. (ATC 밀폐 안 됨)
• 확인(OK): 계속 / 취소(NO): 가공 정지 (공압 부족 시 계속 진행 불가)
• 실제 ATC가 닫혀 있지 않은지 확인하십시오.
• 닫혀 있음에도 메시지 발생 시 ATC를 끝까지 밀어보며 센서 표시를 확인하십시오.
• 공압 차단 후 슬라이드 기구부의 부드러움을 점검하십시오.
A216 Wait 30s for ATC to open. (ATC 개방 대기 중)
• 센서를 통해 ATC가 완전히 열릴 때까지 감지 대기 중입니다. (최대 30초)
A217 Wait 30s for ATC to close. (ATC 밀폐 대기 중)
• 센서를 통해 ATC가 완전히 닫힐 때까지 감지 대기 중입니다. (최대 30초)
A218 Currently equipped tool number. (현재 장착된 공구 일치)
• G코드에서 지시한 공구 번호와 동일한 공구를 이미 장착하고 있는 상태입니다.
• 공구 길이 오프셋 측정 후 밀링이 시작됩니다.
A219 Start tool change. (공구 교체 동작 시작)
• M6 명령 수신 시 지시된 번호로 공구 교체 동작을 시작합니다.
A220 Tool exchange completed. (공구 교체 완료)
• 공구 교체 동작이 정상적으로 완료되었습니다.
A221 Tool touch sensor not detected. (공구 터치 센서 미감지)
• ATC 시작 전 또는 동작 중 터치 센서 신호가 감지되지 않았습니다.
• 센서 주위 분진 청소 및 수동 복귀 테스트를 진행하십시오.
• 복귀 지연이나 신호 불규칙 발생 시 센서 교체가 필요합니다.
A222 Difference in tool length before/after use (가공 전후 공구 길이 차이 측정)
• 밀링 전후 공구 길이를 비교 측정하여 변화값(mm)을 표시합니다.
• 길이 변화가 기준값(0.15mm)을 초과하면 경고 메시지를 출력합니다.
A223 ATC stopped because it was not opened (ATC 개방 실패 정지)
• 개방 동작을 30초간 대기했으나 완료되지 않아 정지했습니다.
• ATC 기구부 및 슬라이드 레일에 뻑뻑함이나 이물질이 없는지 점검하십시오.
A224 ATC stopped because it was not closed (ATC 밀폐 실패 정지)
• 밀폐 동작을 30초간 대기했으나 완료되지 않아 정지했습니다.
• ATC 기구부 및 슬라이드 레일에 뻑뻑함이나 이물질이 없는지 점검하십시오.
A225 Tool usage time (공구 누적 사용 시간)
• 선택한 공구의 누적 가공 시간을 표시합니다.
A226 Reset tool usage time? (선택 공구 사용 시간 초기화)
• 선택한 공구의 누적 사용 시간을 초기화(0)하시겠습니까?
A227 Yes: Reset usage time (전체 공구 사용 시간 초기화)
• 공구 목록 내 등록된 전체 공구의 사용 시간을 리셋합니다.
A228 No: Close message window (메시지 창 닫기)
A229 Tool usage time reset done (공구 사용 시간 초기화 완료)
• 공구의 누적 사용 시간이 성공적으로 초기화되었습니다.
C001 [ Jig 1 for HyperDent ] Ready to calibrate. (hyperDENT용 1번 지그 캘리브레이션 시작)
• 프리밀(Premilled) V1.0 캘리브레이션을 위한 1번 지그 작업을 시작합니다. 준비되면 확인(OK)을 터치하십시오.
C002 [ For HyperDent Jig 2 ] Ready to calibrate. (hyperDENT용 2번 지그 캘리브레이션 시작)
• 프리밀 V1.0 캘리브레이션을 위한 2번 지그 작업을 시작합니다.
C003 [ For HyperDent Jig 3 ] Ready to calibrate. (hyperDENT용 3번 지그 캘리브레이션 시작)
• 프리밀 V1.0 캘리브레이션을 위한 3번 지그 작업을 시작합니다.
C004 [ For HyperDent Jig 4 ] Ready to calibrate. (hyperDENT용 4번 지그 캘리브레이션 시작)
• 프리밀 V1.0 캘리브레이션을 위한 4번 지그 작업을 시작합니다.
C005 [ For HyperDent Jig 5 ] Ready to calibrate. (hyperDENT용 5번 지그 캘리브레이션 시작)
• 프리밀 V1.0 캘리브레이션을 위한 5번 지그 작업을 시작합니다.
C006 Disk AI Calibration incomplete (디스크 AI 캘리브레이션 미완료 경고)
• 종료(Exit): 확인 / 현재 페이지 유지: 취소
• 캘리브레이션을 끝까지 완료하지 않고 마법사를 종료하려 할 때 표시되는 경고입니다.
C007 Premill AI Calibration incomplete (프리밀 AI 캘리브레이션 미완료 경고)
• 종료(Exit): 확인 / 현재 페이지 유지: 취소
• 캘리브레이션을 완료하지 않고 마법사를 닫을 때 표시됩니다.
C008 ATC Auto Calibration incomplete (ATC 오토 캘리브레이션 미완료 경고)
• 종료(Exit): 확인 / 현재 페이지 유지: 취소
• ATC 캘리브레이션을 완료하지 않고 마법사를 닫을 때 표시됩니다.
C009 Calibration Pin Removal incomplete (캘리브레이션 핀 제거 미완료 경고)
• 종료(Exit): 확인 / 현재 페이지 유지: 취소
• 캘리브레이션 핀 제거 단계 완료 전에 마법사를 종료할 때 표시됩니다.
C010 Manual Calibration incomplete (매뉴얼 캘리브레이션 미완료 경고)
• 종료(Exit): 확인 / 현재 페이지 유지: 취소
• 수동 캘리브레이션 진행 중 창을 닫을 때 표시됩니다.
C011 Ready for Disk AI Calibration. (디스크 AI 캘리브레이션 시작 확인)
• 프로브 핀과 지그 간의 전기적 도통 상태를 점검한 후 이상이 없으면 측정을 시작합니다.
