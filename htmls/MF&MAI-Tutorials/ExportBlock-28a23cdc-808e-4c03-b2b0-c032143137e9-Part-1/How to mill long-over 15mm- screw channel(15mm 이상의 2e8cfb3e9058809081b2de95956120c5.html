How to mill long-over 15mm- screw channel(15mm 이상의 긴 스크류 채널 가공하는 법)

1. Requirements(준비물)

You can check your hyperDENT version by pressing F12 on your keyboard


하이퍼덴트 버전은 키보드 F12를 누르면 확인하실 수 있습니다

1)hyperDENT Version 10.1.1 or higher

하이퍼덴트 버전 10.1.1 이상

You can check you database version by pressing F4 on yon your keyboard

키보드 F4를 누르면 데이터 베이스 버전을 확인하실 수 있습니다.

2)MAI DB(database) 251115 or later

MAI 데이터 베이스 251115 이상

3)T01, T23 tools
T01, T23 공구

2. How to Calculate(계산법)

  • Once all setup is complete, please start calculating as usual.
    평소처럼 설정을 마친 뒤 계산 버튼을 눌러주세요.
  • After calculation is done, please enter the ‘show toolpath’ menu to edit NC file.
  • 계산 완료 후 NC 파일 편집을 위해 공구 ‘경로보기’로 가주세요.
  • Separate all connector-related processes to create a new NC file. Two files will be generated: one for bar milling only (NC1) and another for connector milling only (NC2). Please refer to the link for instructions on how to edit NC files.💯How to edit the NC file.
  • 커넥터 관련 공정은 모두 따로 빼내 새 NC를 만듭니다. 바 가공 nc와(NC1) 커넥터만 가공하는 nc 파일 (NC2) 총 2개가 생성됩니다. NC파일 편집법은 해당 링크를 참고. 💯How to edit the NC file.
  • Then, please unlock the STL file that was calculated just before. (short cut: Ctrl +L)

    그런다음 방금 계산한 STL을 잠금해제 해주세요. (단축키: Ctrl +L)

  • Select the template titled “####_Screw Head(T cut)” and calculate again (NC2)

    템플릿 중 “####_Screw Head(T cut)”를 선택한 다음 다시 계산하세요(NC2)

  • Please process the milling sequentially using the three NC file : NC1 (bar milling), NC2 (additional hole milling), and NC3 (connector cutting). Before the process NC3 please check the fit.
  • 이제 NC1 (바 가공)→ NC2(홀 추가가공)→적합 확인→NC3(커넥터 가공) 순서대로 돌려주세요. NC3 돌리기 전에 적합을 확인해주세요.

3. Working principle(가공 원리)

  • Milling up to 20mm using the Zir 2.0B tool(T01) -NC1
    지르코니아 전용 공구를 이용해 20mm 까지 가공합니다.(T01) - NC1
  • However, un-milled areas still remain (marked with green circles).
    하지만 여전히 가공 안되는 부분이 남아있습니다 (초록 원)
  • Mill that area using a T-cutter. -NC2
    해당 부분을 T 커터로 가공합니다. -NC2

4. Precaution(주의사항)

  • The risk of tool damage is extremely high since Titanium or PMMA is machined with Zirconia tools. Please check tool’s condition after milling.
    지르코니아 공구로 티타늄 혹은 PMMA 가공하기 때문에 공구 손상 위험 굉장히 높음. 가공후에 반드시 공구 상태를 확인할 것.
  • Since T-cutters are not perfectly square, perfect machining is impossible if the screw channel has a right angle.
    T 커터도 직각은 아니기에 만약 스크류 채널이 직각이라면 완벽하게 가공은 안 됨.
