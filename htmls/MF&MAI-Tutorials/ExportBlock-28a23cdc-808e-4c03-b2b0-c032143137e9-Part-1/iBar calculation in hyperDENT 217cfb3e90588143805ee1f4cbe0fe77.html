iBar calculation in hyperDENT

Issued2025년 6월 19일 오전 11:30
TagsTutorials

Since the barrier to access designing All on X is getting lower recently, the demand is increasing.

Let’s take a look together the first step of ibar milling, calculation the ibar in hyperDENT!

  1. Select Parts - Abutment bridge or Abutment crown bridge
    파츠 유형을 선택하세요 - 어버트먼트 브릿지 혹은 어버트먼트 브릿지 크라운을 선택하시면 됩니다.

  1. Main direction: Rotate the object to the position which all screw channels have small angle
    메인 방향: STL을 스크류 채널의 각이 가장 적고, 언더컷이 가장 적은 각도로 회전시키세요.

  1. Set the abutment baselines - the outer line of interface
    인터페이스의 외곽에 어버트먼트베이스라인을 설정하세요

  1. Select the pontic areas (Not essential)
    필수는 아니지만 폰틱 영역을 설정하셔도 됩니다.

  1. Set the screw channels
    스크류 채널을 잡아주세요

  1. Apply the implant interface library
    임플란트 인터페이스 라이브러리를 적용하세요.

  1. Load blank and select jig
    가공할 소재와 지그를 선택하세요


  1. Set connectors
    커넥터를 설정하세요

  1. Set occlusal insertion direction
    교합 삽입 방향을 설정하세요

  1. Select the template
    템플릿을 설정하세요

  1. Start calculation!!
    계산 시작하시면 됩니다.
