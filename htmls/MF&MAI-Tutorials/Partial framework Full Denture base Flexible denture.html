Partial framework / Full Denture base / Flexible denture

Partial Framework

  1. Set the Part type to Partial framework

  1. Set the Main direction. Recommend setting it to the direction that has a minimum undercut from cavity.

  1. Set Occlusal direction. Recommend setting it to the direction that has a minimum undercut from occlusal. (Same as main direction.)

  1. No need to set the margin line (Coping). Once there are undercut areas, set the User-defined areas on.

  1. Available to set the Hole

Full denture base

  1. Set the Part type to Denture base

  1. Set the Main direction. Recommend setting it to the direction that has a minimum undercut from cavity.

  1. Set Occlusal direction. Recommend setting it to the direction that has a minimum undercut from occlusal. (Same as main direction!)

  1. A Margin line(Coping) should be set following the edge.

  1. The Tooth pockets are necessary, too.

  1. Available to set the Hole

Flexible denture

  1. Set the Part type to Flexible denture
  1. Set the Main direction. Recommend setting it to the direction that has a minimum undercut from cavity.

  1. Set Occlusal direction. Recommend setting it to the direction that has a minimum undercut from occlusal. (Same as main direction!)

  1. No need to set the margin line (Coping). Once there are undercut areas, set the User-defined areas on. The Tooth pocket also need to set as User-defined areas.

  1. Available to set the Hole
